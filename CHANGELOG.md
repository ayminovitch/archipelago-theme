# Changelog

## 1.0.0 — 2026-10-21

First release.

- Dark theme with "islands": rounded panels floating on a slightly lighter frame
- Python colors tuned to match JetBrains' Islands Dark editor scheme (keywords, decorators,
  keyword arguments, `self`, docstrings, f-strings, built-ins)
- Supports VS Code's modern floating-panel layout: no panel outlines, pill-style active tab
- Clean colors for JSON, YAML, TOML, Markdown, shell, HTML and `.env` files
